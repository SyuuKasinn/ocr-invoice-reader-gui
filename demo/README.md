# Demo Assets

This folder contains demonstration materials for the OCR Invoice Reader GUI.

## 📁 Files

- `demo.gif` - Main demonstration GIF (10-20 seconds)
- `screenshot-*.png` - Screenshots of key features

## 📸 Screenshots to Capture

1. **screenshot-main.png** - Main interface with drop zone
2. **screenshot-viz.png** - Visualization tab showing OCR boxes
3. **screenshot-json.png** - JSON data tab
4. **screenshot-text.png** - Extracted text tab
5. **screenshot-tables.png** - HTML tables tab

## 🎬 GIF Requirements

- **Duration**: 10-20 seconds
- **Size**: Under 5MB (preferably 2-3MB)
- **Frame Rate**: 10-15 FPS
- **Resolution**: 1000x800 or similar

## 📋 What to Show in GIF

1. Empty GUI with drop zone (2s)
2. Drag and drop a file (3s)
3. Click "Process Document" (1s)
4. Show progress bar (2-3s)
5. Display results in tabs (5-8s)
   - Visualization tab
   - JSON tab
   - Text tab
   - Tables tab

## 🔗 Usage in README

Once you have the GIF, it will be displayed in the main README like this:

```markdown
## 🎥 Demo

![OCR Invoice Reader GUI Demo](demo/demo.gif)

*Drag, drop, and view OCR results instantly*
```

## 📝 Notes

- Use the international waybill example for demonstration
- Keep mouse movements smooth and purposeful
- Pause briefly on each tab to show content
- Ensure text is readable in the recording
