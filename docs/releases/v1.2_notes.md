## ⚡ Performance Improvements

### Speed Comparison

| Scenario | v1.0 | v1.2 Optimized | Improvement |
|----------|------|----------------|-------------|
| App Startup | 5s | 2s | **2.5x faster** ⚡ |
| First OCR Scan | 15s | 15s | Same (model loading) |
| 2nd Scan Onward | 15s | **3s** | **🔥 5x faster** ⚡⚡⚡ |
| Batch 10 Files | 150s | **42s** | **3.6x faster** ⚡⚡ |

### How It Works

**❌ Original (v1.0):**
```
Each scan → Launch new process → Load OCR model (10-20s) → Process → Exit
```

**✅ Optimized (v1.2):**
```
Startup → Load model once (10s) → Keep in memory
Each scan → Use pre-loaded model → Process immediately (3s)
```

**Key Innovation:** Pre-loaded OCR engine eliminates repeated model loading!

## 🚀 Quick Start

### Installation

1. **Download** `OCR-Invoice-Reader-Optimized-v1.2.tar.gz`
2. **Extract** the archive
3. **Navigate** to extracted folder
4. **Double-click** `RUN_ME.bat` or `OCR-Invoice-Reader-Optimized.exe`

### First Run

⚠️ **Important:** First run will automatically download AI models (~300MB)

- **Download location:** `C:\Users\<YourName>\.paddleocr\`
- **Download time:** 1-5 minutes (depends on internet speed)
- **One-time only:** Models are cached permanently after download

### Basic Usage

1. Wait for splash screen (startup, ~10 seconds first time)
2. Drag & drop your PDF or image file
3. Select language (Chinese/English/Japanese/Korean)
4. Choose OCR mode (ocr-extract recommended)
5. Click "Process Document"
6. View results in tabs (Visualization/JSON/Text/Tables)

## 💡 Performance Tips (Get Maximum Speed!)

### Tip 1: Keep Application Open ⚡⚡⚡

❌ **Wrong Way:**
```
Process file 1 → Close app → Reopen → Process file 2 → Close...
Every time: 15 seconds (reloads model)
```

✅ **Right Way:**
```
Open once → Process all files continuously
File 1: 15s (first time)
File 2: 3s ⚡ (5x faster!)
File 3: 3s ⚡
File 4: 3s ⚡
...
```

**Result:** Save 12 seconds per file after the first one!

### Tip 2: Choose Right OCR Mode

| Mode | Speed | Accuracy | Best For |
|------|-------|----------|----------|
| `ocr-simple` | ⚡⚡⚡ Fastest (1-2s) | Low | Quick preview |
| `ocr-raw` | ⚡⚡ Fast (2-3s) | Medium | Simple documents |
| `ocr-extract` | ⚡ Medium (3-5s) | High | **Invoices** ✅ |
| `ocr-enhanced` | 🐌 Slow (5-8s) | Highest | High quality needs |

**Recommendation:** Start with `ocr-simple` for quick preview, then use `ocr-extract` for final processing.

### Tip 3: GPU Acceleration (Optional) ⚡⚡

**Requirements:**
- NVIDIA GPU
- CUDA 11.2+
- cuDNN 8.2+

**Performance Boost:**
- CPU mode: 3 seconds
- GPU mode: **1.5 seconds** (2x faster!)

**How to Enable:**
1. Check "Use GPU (if available)" in application
2. First run verifies CUDA installation

## 📋 Known Issues & Solutions

### 1. Antivirus False Positive

**Issue:** Some antivirus software may flag the executable  
**Solution:** Add to whitelist or run from Python source  
**Reason:** PyInstaller executables sometimes trigger heuristic detection

### 2. First Run is Slow

**Issue:** First run takes ~10 seconds + model download time  
**Solution:** Be patient, this is one-time only  
**Note:** Models (~300MB) are downloaded and cached permanently

### 3. Large File Size

**Issue:** 193MB compressed, 531MB uncompressed  
**Explanation:** Includes complete PaddleOCR engine and all dependencies  
**Benefit:** No separate installation needed, runs standalone
