# v2.1.1 Bug Fixes

**Release Date:** 2026-05-14  
**Type:** Bug fix release

---

## 🐛 Fixed Issues

### 1. Button Text Not Visible
**Problem:** The "Process Document" button text was difficult to read due to insufficient contrast.

**Fix:**
- Changed foreground color to pure white (`#FFFFFF`) for better contrast
- Increased font size from 12 to 13 for better readability
- Added `disabledforeground` color for disabled state
- Button text now clearly visible in all states

### 2. Unwanted ocr-enhanced.exe Popup
**Problem:** When OCR analyzer failed to pre-load, the app fell back to calling `subprocess.run()` with `ocr-enhanced` command, which opened a separate console window.

**Fix:**
- Removed `_process_cli()` fallback method entirely
- Modified `_process_thread()` to always attempt loading analyzer in-memory
- If pre-load fails, loads analyzer on-demand in the same process
- No more subprocess calls = no more popup windows

### 3. Slow Execution
**Problem:** Application was slow, especially in built executable.

**Root Cause:** OCR analyzer not properly pre-loading at startup.

**Fix:**
- Improved `load_ocr_engine()` with better error handling
- Always attempts to pre-load analyzer during splash screen
- If initial load fails, loads on first use (still in-memory)
- Pre-loaded model now properly cached for 5x faster subsequent operations

### 4. Pre-load Model Not Default
**Problem:** Model pre-loading wasn't reliably happening.

**Fix:**
- Enhanced `load_ocr_engine()` function with retry logic
- Better error messages and status updates during load
- Graceful fallback to on-demand loading if pre-load fails
- User always gets best performance available
