**Type:** Critical bug fix release

## 🐛 Fixed Critical Issues

### 1. "no module named ocr_invoice_reader" Error
**Problem:** When running the exe file, it would fail with `ModuleNotFoundError: No module named 'ocr_invoice_reader'`

**Root Cause:**
- PyInstaller wasn't including the `ocr-invoice-reader` package correctly
- The package is installed as editable (development mode)
- Need to explicitly tell PyInstaller where to find it

**Fix:**
- Added `ocr-invoice-reader` path to PyInstaller's `pathex`
- Included the entire package as data files
- Now correctly bundles all dependencies

```python
# In spec file:
ocr_invoice_reader_path = r'C:\Users\kants\Desktop\ocr-invoice-reader'
pathex=[ocr_invoice_reader_path]
datas=[(ocr_invoice_reader_path, 'ocr_invoice_reader')]
```

### 2. Very Slow exe Loading
**Problem:** Clicking the exe file took very long to start

**Root Cause:**
- Previous code tried to import complex modules before showing splash screen
- Import errors were silently caught, causing delays

**Fix:**
- Simplified the OCR engine loading process
- Uses `OCRInvoiceReader` class directly from ocr-invoice-reader
- Faster initialization with better error handling
