**Type:** Critical API fix

## 🐛 Fixed Issue

### "Failed to load OCR engine" Error - FIXED!

**Problem:**  
Application showed "Failed to load OCR engine" error when starting or processing files.

**Root Cause:**  
- Code was trying to import `OCRInvoiceReader` class which doesn't exist
- The correct class in ocr-invoice-reader package is `DocumentExtractor`
- Wrong API method calls

**Fix:**  
✅ Changed to use correct `DocumentExtractor` class  
✅ Updated initialization: `DocumentExtractor(use_gpu, lang)`  
✅ Updated processing: `extractor.extract(file_path, visualize)`  
✅ Added proper result conversion: `document.model_dump()`

---

## 🔧 Technical Changes

### Before (v2.1.2 - WRONG):
```python
from ocr_invoice_reader import OCRInvoiceReader  # ❌ Doesn't exist!
analyzer = OCRInvoiceReader(use_gpu=False)
result = analyzer.process(...)  # ❌ Wrong method!
```

### After (v2.1.3 - CORRECT):
```python
from ocr_invoice_reader import DocumentExtractor  # ✅ Correct class
extractor = DocumentExtractor(use_gpu=False, lang='ch')
document = extractor.extract(file_path, visualize=True)
result = document.model_dump()  # Convert to dict
```

## 🔗 API Reference

Using **ocr-invoice-reader** package correctly:

```python
from ocr_invoice_reader import DocumentExtractor

# Initialize
extractor = DocumentExtractor(
    use_gpu=False,  # or True if NVIDIA GPU
    lang='ch'       # or 'en', 'japan', 'korean'
)

# Extract from file
document = extractor.extract(
    image_path="invoice.pdf",
    visualize=True  # Save visualization
)

# Access results
print(document.model_dump())  # All extracted data
```
