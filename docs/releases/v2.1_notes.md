## 🔄 Migration Guide

### For Existing Users

1. **Download v2.1**
   - New executable: `OCR-Invoice-Reader-Modern-v2.1.exe`
   - Completely standalone, no uninstall needed

2. **First Run**
   - May download updated PaddleOCR v4 models (~300MB)
   - One-time download, then cached locally
   - Faster recognition after download

3. **Settings Compatibility**
   - All previous settings work
   - Same OCR modes and languages
   - Same output formats

### For Developers

1. **Updated API**
   ```python
   # Old (v1.2)
   from ocr_invoice_reader import OCRInvoiceReader
   ocr_reader = OCRInvoiceReader()
   
   # New (v2.1)
   from ocr_invoice_reader.processors.enhanced_structure_analyzer import EnhancedStructureAnalyzer
   analyzer = EnhancedStructureAnalyzer(use_gpu=False, lang='ch')
   result = analyzer.analyze(file_path, lang=lang, visualize=True)
   ```

2. **New File**
   - Main file: `src/ocr_gui_modern.py`
   - Old files still available for reference
   - All English, clean structure
